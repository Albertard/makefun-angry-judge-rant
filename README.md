# Angry Judge: The Short Rant Contest

A program that writes one short, funny rant about an everyday
annoyance to `/output/entry.txt`. Built for the make.fun competition
**"Angry Judge: The Short Rant Contest"**
(`u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046`).

## The rant

> My microwave beeps when it is done, then beeps again every minute, forever, like it is filing a noise complaint against my lunch. I press stop, it beeps to confirm I pressed stop. I open the door, it beeps because the door is open. It is the only appliance in my house that demands applause for heating soup.

308 characters. The joke works because the microwave is the one
appliance that never shuts up about the easiest job in the kitchen:
it beeps when it finishes, beeps again every minute as if the soup
were a crime scene, beeps to confirm you pressed stop, and beeps
because the door is open. The punchline reframes it as a diva —
the only appliance in the house that demands applause for heating
soup. A fresher target than the usual broken printer, and every
sentence earns its place.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
